# github
我的Github使用经验总结

## License
1. license在repository创建时才能选择，选择之后就不能改成其它的license了，但可以更新具体的license的文本内容

## Issues
需求和bug作为不同类别，但都是issue。

## 项目project和repository
仓库里面可以没有项目，仓库可直接操作，也就是说针对仓库来说，是否新建项目是个可选项。但是新建项目必须选择对应的仓库

## Milestone
milestone的值要在repository中的issue里面设置具体的值，在项目里面是不能该这个值的可选项的。

## Pull request
多人提交代码时每次做合并代码时的操作。
